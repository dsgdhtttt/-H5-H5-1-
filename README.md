# 新版同城搭子游玩活动线下组局上门陪约玩助教H5源码伴伴找搭子系统源码H5同城组局

源码获取：ym7k.com/19816/

**技术栈：FastAdmin + ThinkPHP + UniApp**
✅ H5 端为主，可编译微信小程序；PC 管理后台，一套 UniApp 源码，主打同城兴趣组局、达人助教预约、上门陪约，本地兴趣社交服务平台，无加密源码，私有化部署、二开。

> 
> 业务定位：和伴伴、搭子社交平台类似，分两大主线：**用户自主线下组局** + **达人 / 助教预约接单（陪玩、助教、陪同服务）**

## ✅ 核心功能模块

### 1. 用户端（H5 / 小程序）

- 定位 LBS 同城推荐，按距离筛选搭子、活动、达人
- 个人主页：头像、标签、兴趣爱好、自我介绍、评价、相册
- 实名认证、性别、年龄、兴趣标签（桌游、徒步、羽毛球、探店、观影、学习助教等）
- 私信聊天、关注、拉黑、举报

### 2. 线下组局活动模块（自主搭子）

- 用户发布组局：选择分类、时间、地点、人数上限、AA / 自费 / 免费、费用、活动图文、集合地点地图
- 活动类型：运动、桌游、美食、探店、露营、读书、观影、游玩等
- 报名缴费、名额限制、报名名单查看、核销签到
- 活动评论、活动结束后评价、活动相册
- 活动审核：后台审核，违规活动直接驳回

### 3. 达人 / 助教预约陪约模块（上门 / 线下陪同）【本系统特色】

- 达人入驻申请，后台审核资质、头像、技能标签、服务介绍、服务范围、价格、是否支持上门
- 服务分类：学习助教、游戏陪玩、运动陪同、逛街陪同、拍照陪拍等
- 预约下单：选择服务时段、地址、上门 / 到店、线上支付
- 订单流程：下单→达人接单→待履约→完成→评价
- 达人价格自定义、按时长计费、多时段可约、接单开关

### 4. 订单、支付与资金

- 微信支付、支付宝 H5 支付
- 平台抽佣：组局服务费、达人订单抽成，后台自定义比例
- 达人佣金、佣金提现、提现审核、资金流水
- 退款管理、订单维权、纠纷处理

### 5. 营销模块

- 优惠券、新人券、分享奖励
- 分销推广：邀请好友注册、发活动拿奖励
- 置顶付费：活动 / 达人付费置顶，提升曝光
- 会员套餐：会员免服务费、优先匹配、置顶折扣

### 6. 后台管理（FastAdmin）

RBAC 多角色权限：超级管理员、审核员、财务

- 用户管理、达人管理、入驻审核、实名认证审核
- 活动分类、服务分类管理、标签管理
- 活动审核、订单管理、提现审核、举报处理
- 数据看板：活动数量、报名人数、订单金额、达人营收、用户增长图表
- 评价管理、敏感词过滤、消息通知配置
- 地图配置、短信、模板消息、OSS 存储

### 7. 消息通知

- H5 消息、小程序订阅消息：报名成功、达人接单、预约提醒、提现通知、活动提醒

## 🖥️ 部署环境

- PHP7.4，MySQL5.7/8.0，Nginx
- HBuilderX 打开 UniApp 源码，编译 H5，可选编译微信小程序
- 需要高德 / 百度地图定位接口、短信、支付接口
